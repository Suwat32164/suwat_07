# 💻 E-Portfolio | ครูผู้สอนด้านเทคโนโลยีและการเขียนโปรแกรม

เว็บไซต์แฟ้มสะสมผลงานอิเล็กทรอนิกส์ (E-Portfolio) สำหรับครูผู้สอนรายวิชาคอมพิวเตอร์ วิทยาการคำนวณ และการเขียนโปรแกรม พัฒนาขึ้นด้วย HTML5, CSS3 และ JavaScript ภายในไฟล์เดียว (`index.html`) ออกแบบให้เรียบง่าย ทันสมัย ในโทนสีน้ำเงิน–ขาว และพร้อมเผยแพร่ผ่าน **GitHub Pages** ทันที

---

## ✨ คุณสมบัติหลัก (Features)

* **โครงสร้างครบ 4 ส่วนสำคัญ:**
  1. **หน้าแรก (Home):** แนะนำตัวตน แนวคิดการสอน และปุ่มเข้าถึงคลังโค้ด GitHub
  2. **แนะนำตัว (About):** ประวัติการศึกษา ปรัชญาการจัดการเรียนรู้ และทักษะด้านเทคโนโลยี
  3. **ผลงาน (Portfolio):** การ์ดแสดงผลงานและสื่อการสอน พร้อมระบบกรองหมวดหมู่ (ทั้งหมด / เว็บแอปพลิเคชัน / สื่อการสอน / นวัตกรรม IoT)
  4. **กิจกรรม (Activities):** ไทม์ไลน์แสดงประสบการณ์การเป็นวิทยากร การอบรม และกิจกรรมพัฒนาผู้เรียน
* **Single-File Architecture:** รวมโครงสร้าง HTML, สไตล์ CSS และสคริปต์ JavaScript ไว้ในไฟล์ `index.html` เพียงไฟล์เดียว ไม่ต้องติดตั้ง Framework หรือ Library เพิ่มเติม
* **Responsive Design:** รองรับการแสดงผลทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ (พร้อมเมนู Hamburger สำหรับหน้าจอขนาดเล็ก)
* **รองรับภาษาไทยสมบูรณ์:** ใช้ฟอนต์ **Prompt** จาก Google Fonts เพื่อความคมชัดและอ่านง่าย
* **Public-Safe Footer:** ส่วนท้ายเว็บไซต์ออกแบบสำหรับแสดงข้อมูลติดต่อที่เหมาะสมต่อการเผยแพร่สาธารณะ

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5** — โครงสร้างเนื้อหาเชิงความหมาย (Semantic HTML)
* **CSS3** — จัดการเลย์เอาต์ด้วย Flexbox & CSS Grid, CSS Variables สำหรับธีมสี และ Media Queries
* **Vanilla JavaScript (ES6+)** — ควบคุมเมนูมือถือ, ระบบกรองการ์ดผลงาน (Category Filter) และ Scroll Spy ไฮไลต์เมนูตามตำแหน่งหน้าจอ
* **Google Fonts** — ฟอนต์ `Prompt`
